# 🎮 Nível do Herói

Projeto desenvolvido utilizando **HTML, CSS e JavaScript**, com o objetivo de praticar conceitos fundamentais de desenvolvimento web, manipulação do DOM, formulários, eventos e lógica de programação.

---

## 📖 Sobre o Projeto

O sistema permite que o usuário informe:

* 🦸 Nome do Herói
* ⭐ Quantidade de XP (Experiência)

Após o envio dos dados, o sistema calcula automaticamente o nível do herói e exibe o resultado em uma segunda tela.

Toda a navegação acontece na mesma página, utilizando JavaScript para alternar entre as telas sem necessidade de recarregar o navegador.

---

## 🚀 Funcionalidades

✅ Cadastro do nome do herói

✅ Cadastro do XP do herói

✅ Validação dos campos

✅ Cálculo automático do nível

✅ Exibição personalizada do resultado

✅ Interface responsiva para desktop e dispositivos móveis

✅ Possibilidade de realizar uma nova consulta

---

## 🏆 Tabela de Níveis

| XP                     | Nível      |
| ---------------------- | ---------- |
| Menor ou igual a 1.000 | Ferro      |
| 1.001 até 2.000        | Bronze     |
| 2.001 até 5.000        | Prata      |
| 5.001 até 7.000        | Ouro       |
| 7.001 até 8.000        | Platina    |
| 8.001 até 9.000        | Ascendente |
| 9.001 até 10.000       | Imortal    |
| Maior que 10.000       | Radiante   |
